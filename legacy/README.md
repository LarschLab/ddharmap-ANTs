# Legacy material

This directory contains historical notebooks, registration scripts, and analysis artifacts retained for provenance or explicit reproduction.

- Legacy code is not current scientific or implementation authority.
- Do not import legacy modules from current package code.
- Do not route ordinary tasks here.
- For an explicit reproduction, read the current scientific policy and stage map first, then document every intentional historical deviation.
- Moving a file here preserves it; deletion requires a separate provenance and recovery decision.

## Contents

- `notebooks/`: historical notebook implementations, including `antsQC.ipynb` and the pre-package single-fish notebook.
- `registrations/`: superseded registration and parameter-sweep scripts.
- `analysis-artifacts/`: retained one-off scripts and generated evidence.
- `pre-cleanup-snapshots/`: files that were untracked before the explicit `pre-cleanup` snapshot and have current authoritative counterparts elsewhere.
